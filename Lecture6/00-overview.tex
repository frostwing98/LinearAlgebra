\begin{frame}{Learning Goals}
  By the end of the lecture, you should be able to
  \begin{itemize}
    \item compute small determinants directly;
    \item use minors and cofactors to expand along any row or column;
    \item choose an efficient cofactor expansion;
    \item track how elementary row or column operations change a determinant;
    \item combine elimination and cofactor expansion for larger matrices.
  \end{itemize}
\end{frame}
